# 📚 BookStore - MERN Stack Application

A full-stack BookStore web application built using the MERN Stack (MongoDB, Express.js, React.js, Node.js). This project allows users to browse books and provides a modern frontend with a scalable backend architecture.

## 🚀 Tech Stack

### Frontend

* React.js
* Vite
* React Router
* Axios
* CSS

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose

## ✨ Features

* User Authentication (Login / Signup)
* Browse Books
* Responsive User Interface
* REST API Integration
* MongoDB Database Connectivity
* Modern React Components



## 🎯 Future Improvements

* Book Search Functionality
* Wishlist Feature
* Admin Dashboard
* Book Reviews & Ratings
* Payment Gateway Integration
